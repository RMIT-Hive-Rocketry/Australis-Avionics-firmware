# Glossary


### AV2

Strictly refers to the PCB which *Australis* currently targets.

### Australis

Strictly refers to this firmware project. It is not necessarily for *AV2*, but at
the moment this is the case.

### CAN

CAN stands for Controller Area Network. It is a unique communication protocol.
It has the concept of a 'bus' which many devices share, and messages are
broadcast to anything that is listening to the bus. A CAN packet has an ID, but
this is not the device ID, but the ID of what the data is. A CAN packet holds
up to eight bytes of data.
