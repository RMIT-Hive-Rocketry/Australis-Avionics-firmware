./output
  Generated during build.
  Final build outputs go here.
./output/lib
         For each target, holds static libraries, such as the FreeRTOS kernel and Australis external library.
./output/map
         For each target, holds their memory maps, text files describing memory locations of functions and variables.
./output/bin
         For each target, contains the final ELF file that is flashed to the board.
